# SmartBrowser 2.0.6 Installer Archive

This tag preserves the installer built before the Selection Profile / Usage work
in SmartBrowser 2.1.0.

The original full source snapshot was not committed. This archive contains only
this record and the installer's SHA-256 checksum. It is not a source checkout of
2.0.6 and must not be used to rebuild that release.

Download `pkg_smartbrowser-v2.0.6.zip` from this tag's GitHub release assets. Do not
use GitHub's automatically generated source ZIP/TAR archives as Joomla installers.

The installer includes the 2.0 resource visuals/icon settings, Collection View,
SmartVisuals integration, optional SmartCrop rendering, frontend editor fixes and
remembered popup maximization/modal backdrop changes. Selection Profiles are
introduced separately in 2.1.0.
